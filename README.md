## 🚀 Quick Start

```bash
# 📥 Clone repository
git clone https://github.com/username/layanan-digital.git
cd layanan-digital

# 📦 Install dependencies
npm install

# ⚙️ Setup environment
# Copy dan edit file .env dengan konfigurasi Anda
cp .env.example .env

# ▶️ Jalankan development server
npm run dev

# 🏗️ Build untuk production
npm run build
```
